### pmEnabled flag creates inconsistent L1 availability accounting — supplied assets ignored when flag is false

**Severity (estimated):** Low  
**Confidence:** 0%  
**Affected:** _sendL1Bridge, emergencyBridgePrincipalFromL1

**Why needs review:** The PoC did not succeed, but the vulnerability hypothesis is plausible based on code analysis. A human auditor must determine whether this is a real issue.

**Attack scenario:** 1. The Vault has USDC supplied to the 0x811 Portfolio Margin pool (suppliedBalance > 0). 2. pmEnabled is set to false (e.g., due to a configuration change or initialization timing). 3. Governor calls emergencyBridgePrincipalFromL1 to bridge principal back from L1. 4. _sendL1Bridge only counts spotBalance.total, ignoring the supplied balance. 5.
