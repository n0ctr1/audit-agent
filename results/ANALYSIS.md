## 4. Exploited: raw vs strict

Raw = Exploit status `exploited` (the forge test passed). Strict = additionally (a) the test calls a contract defined in scope, (b) no `assertTrue(true)` / `assert(true)` in any form, (c) no assertion comparing two identical expressions over the same arguments, (d) the `-vvvv` trace (re-run by `benchmark retrace`, no LLM) shows a passing assertion after a successful (not reverted) call to an in-scope contract. Checks (b) and (c) read the stored PoC code, (a) and (d) the re-run trace. forge-std ≥ 1.10 calls `vm.assert*` only when an assertion fails, so for such projects a passing assertion is invisible: (d) is then *undetermined* if a successful in-scope call exists and *no* only if there is none. `–` = not available (no re-run trace / not determinable).
